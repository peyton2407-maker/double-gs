# Double Gs

NFL + college football projection board: lines, weather, player props, and CFB picks.

## Open it

- Repo file: [index.html](https://github.com/peyton2407-maker/double-gs/blob/main/index.html)
- Raw file (download / open): https://raw.githubusercontent.com/peyton2407-maker/double-gs/main/index.html

### GitHub Pages (public link that just works in a browser)

1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. After a minute the board is at:

`https://peyton2407-maker.github.io/double-gs/`

## Notes

Snapshot is baked into the HTML. **Refresh lines + weather** needs internet (ESPN + Open-Meteo). Projections are informational, not betting advice.
